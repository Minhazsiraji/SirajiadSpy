# SirajiadSpy

A low-cost, browser-only competitor ad research and creative strategy MVP for Bangladesh, designed in the AgentSiraji visual system. It implements the Day 5 workflow without claiming access to private competitor performance data.

## Run

Open `index.html` directly, or serve the folder with any static server (for example `npx serve .`). No build step or API key is required.

## Workflow

1. Add product, audience, offer context, and an image.
2. Open a pre-filled Bangladesh search in Meta Ad Library.
3. Save observable evidence from active competitor ads: days active, first-three-second hook, format, angle, and comments.
4. Generate five hook tests, an offer direction, a white-space angle, and a 20–35 second shooting brief.

Inputs are saved in browser `localStorage`; product images are previewed locally and are not persisted or uploaded.

## Important limitation

Ad longevity is treated as a research signal—not proof of profitability. Meta's public Ad Library exposes active commercial ads, but not their private revenue, ROAS, conversion count, or exact profitability.
